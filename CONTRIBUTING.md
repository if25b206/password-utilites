# Contributing

Thanks for your interest in contributing!

## Reporting Issues

If you find a bug, please open an issue using the issue template.
Describe the problem and include steps to reproduce it.

## Requesting Features

If you have an idea for a new feature, open an issue using the feature request template.

## Submitting a Pull Request

1. Fork the repository
2. Create a new branch for your change
3. Make your changes and add tests if needed
4. Run `npm test` to make sure everything still works
5. Open a pull request and describe what you changed

Please keep pull requests small and focused on one thing.
